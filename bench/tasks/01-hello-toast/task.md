# Greeting

Build an abap2UI5 app in the ABAP class `zcl_bench_01`.

The screen asks the user for their name: a page titled "Greeting" with an
input field for the name and a button "Greet". Pressing the button shows a
short message toast "Hello, <name>!" with the name that was typed in.

Deliver the class in abapGit format in the folder `src/`:
`src/zcl_bench_01.clas.abap` and its metadata file `src/zcl_bench_01.clas.xml`.
The app must run on abap2UI5 1.145.0 and SAPUI5 1.71 or later.
